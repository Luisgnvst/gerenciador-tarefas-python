# Gerenciador de Tarefas em Python

Um gerenciador de tarefas via terminal, feito em Python, com salvamento automático de dados em arquivo (JSON) — as tarefas continuam salvas mesmo depois de fechar o programa.

## Funcionalidades

- ✅ Adicionar tarefas
- 📋 Listar tarefas (numeradas)
- 🗑️ Remover tarefas por número
- 💾 Persistência de dados: as tarefas são salvas automaticamente em um arquivo `tarefas.json`

## Como rodar

1. Tenha o Python instalado (versão 3.10 ou superior)
2. Clone este repositório:
```bash
git clone https://github.com/Luisgnvst/gerenciador-tarefas-python.git
```
3. Entre na pasta do projeto e rode:
```bash
python main.py
```

## O que aprendi construindo esse projeto

- Estruturas de repetição (`while`) e condicionais (`if/elif/else`)
- Manipulação de listas (`.append()`, `.pop()`, `enumerate()`)
- Leitura e escrita de arquivos com o módulo `json`
- Tratamento de erros com `try/except`
- Fluxo de versionamento com Git e GitHub (commits, push)

## Tecnologias

- Python 3
